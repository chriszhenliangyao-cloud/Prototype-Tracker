# ERP 模块原生整合本地测试

入口：`index.html`

本测试版将以下模块放入同一个运营协同平台壳内，不使用 iframe：

- 预测管理
- 物流交付
  - 发货汇总（市场、PO、批次、时间周期与异常履约汇总）
  - 发货操作（PO 状态看板与分批发货操作台）
  - 产品物流与价格（包装、库存、RRP 与 Invoice Price）
- BP达成（年度/季度达成、市场与品类、产品明细和确认版本）
- 经营分析复盘（月度、季度、半年度和年度冻结复盘、费用穿透、行动闭环与历史归档）
- 职能工作台
  - 样机管理（需求、流转、借用归还和历史记录）

数据来自提供文件的只读快照。原始文件未被修改；演示中的编辑、发货和保存操作只在当前浏览器会话中生效，不写入协同平台数据库。

预测模块原 Demo 中固定出现的“共享数据已更新”提示已在本测试副本中移除。正式接云端时仅在检测到真实版本冲突后显示，不会每次进入页面都提示。

可以直接双击 `index.html` 打开。若浏览器限制本地脚本，则在本目录运行静态服务器后访问：

```bash
python3 -m http.server 8942
```

物流交付子模块 URL 使用 `#module=logistic&view=summary|operation|products`，刷新页面后会恢复当前子模块。BP达成使用 `#module=bp`。
