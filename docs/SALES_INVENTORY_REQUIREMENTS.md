# Sales & Inventory Planning requirements

## Local demo baseline

- Sales & Inventory remains a Mock Data demonstration and does not write to a
  database.
- Its browser-local workspace is isolated from every other ProtoTrack module.
- The current demo baseline starts at `Jul 2026 · Open` and includes July plus
  the following three forecast months.
- The Sales & Inventory local-storage version is `v2`. This version reset is
  intentionally limited to this module so Project Progress and all other page
  data remain unchanged.
